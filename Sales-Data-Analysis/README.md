# Sales Data Analysis Project

## Overview
This project analyzes sales transactions using MySQL, Microsoft Excel, and SQL queries. It explores revenue, profit, product performance, and monthly sales trends.

## Tools Used
- MySQL
- SQL
- Microsoft Excel
- GitHub

## Dataset
The dataset contains 12 sample sales transactions across four regions, covering January to March 2026.

## Key Metrics
- Total Revenue: ₹486,900
- Total Profit: ₹125,500
- Total Units Sold: 48
- Total Orders: 12

## Analysis Performed
- Calculated revenue and profit for each order.
- Compared revenue and profit across products.
- Analyzed monthly revenue trends.
- Created an Excel dashboard with key performance indicators and charts.

## Key Findings
- Laptop generated the highest revenue.
- Laptop generated the highest profit.
- March had the highest monthly revenue among the three months analyzed.

## Files
- `sales_data.csv` — sales dataset.
- `Sales_Data_Analysis.xlsx` — Excel analysis and dashboard.

## Note
The dataset is a small sample created for learning and portfolio demonstration. The results should not be interpreted as actual business performance.
